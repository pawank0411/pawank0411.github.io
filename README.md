# Navratri Memories — bilingual website

English text is followed by Hindi translations throughout the page.

## Setup
1. Edit `index.html` and add your nine Google Drive folder URLs in the `albums` array.
2. Add Pawan's photo at `images/pawan-profile.jpg` (create an `images` folder beside `index.html`).
3. Replace LinkedIn and WhatsApp `href="#"` placeholders with real URLs.
4. Deploy this folder at https://app.netlify.com/drop.
